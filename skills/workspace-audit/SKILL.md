# 全库体检

## 先跑算法能查的

`python3 scripts/audit.py` 会用纯算法查出五类问题并输出 JSON：
内部矛盾、过期未动、缺失字段、重复记录、以及格式层面的事实错误（DOI 格式、日期合法性、链接可达性）。
**这部分不要你做**，你只读它的结果。

## 你要做的：需要理解力的那一类

1. **引用真伪** —— `reading/` 和 `reports/` 里提到的文献是否真实存在。
   必须调用 `academic-literature-review` 技能核验，**宁可标注「无法确认」也不要猜**。
2. **语义重复** —— 算法只能查字面重复；换了说法的同一个想法要靠你判断。
3. **事实是否过时** —— 例如某会议官网已改期、某期刊已改名或停刊。有把握才报。

## 输出

写进 `data/_claude/audits/YYYY-MM-DD.md`，格式：

```
## 高 · 内部矛盾
- [manuscripts/xxx.md] stage 写作 `submitted`，但时间线最后一条是 `rejected`（2026-06-02）
  建议：改为 `writing`，或补一条新的投稿事件
```

分三级：**高**（数据自相矛盾或明显错误）、**中**（可能过时、需要确认）、**低**（缺字段、格式不规范）。

## 铁律

**只提议，不修改。** 唯一允许自动执行的是给失效链接加 `link_dead: true` 标记。
每条必须给出：文件位置、问题、建议的修正值。用户在界面上点「采纳」才会真正改动。
被用户「忽略」过的条目记在 `data/_claude/audit-ignored.json`，以后不再报。
