# Scholar Workspace v1.0.0

The first public release of Scholar Workspace: a local-first research command center that keeps readable Markdown files on your own computer.

## Highlights

- Manuscript, journal, conference, literature, idea, and schedule workflows
- Zotero, EndNote, Mendeley, BibTeX, RIS, NBIB, and CSL-JSON indexing
- Linked research records, spaced-review queues, calendar integration, and optional AI tasks
- Persistent Chinese/English interface switch (English beta)
- Fourteen core suites on Python 3.9 and 3.13; Linux, macOS, and Windows startup checks
- Chromium, Firefox, and WebKit interface regression tests
- Sanitized sample data with no personal paths, credentials, device state, or research history

## Install

Download `Scholar-Workspace-v1.0.0.zip`, verify it against `SHA256SUMS.txt`, extract it, and follow the included README. Python 3.9 or newer is required; no Python packages need to be installed.

The application is local by default. LAN access is optional, access-code protected, and read-only until explicitly unlocked.
