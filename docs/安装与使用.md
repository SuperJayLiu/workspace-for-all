# 安装与使用

[English](installation.en.md)

Scholar Workspace 需要 Python 3.9 或更新版本，运行时不需要安装任何 Python 包。

## 1. 准备 Python

检查版本：

```bash
python3 --version
```

- **macOS**：macOS 不保证预装可用的 Python 3。可从 [python.org](https://www.python.org/downloads/macos/) 安装，或使用 Homebrew：`brew install python`。
- **Windows**：从 [python.org](https://www.python.org/downloads/windows/) 安装。安装第一页勾选 **Add Python to PATH**，然后在 PowerShell 运行 `py -3 --version`。

显示的版本必须是 3.9 或更新版本。

## 2. 获取工作台

### 下载发布包（推荐）

打开 [Releases](https://github.com/SuperJayLiu/workspace-for-all/releases/latest)，下载 `Scholar-Workspace-vX.Y.Z.zip` 并解压到一个长期保留的位置。不要直接在 ZIP 内运行。

### 使用 Git

```bash
git clone https://github.com/SuperJayLiu/workspace-for-all.git
cd workspace-for-all
```

## 验证下载包（可选但推荐）

发布页同时提供 `SHA256SUMS.txt`。

macOS / Linux：

```bash
shasum -a 256 Scholar-Workspace-vX.Y.Z.zip
cat SHA256SUMS.txt
```

Windows PowerShell：

```powershell
Get-FileHash .\Scholar-Workspace-vX.Y.Z.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

两个 SHA-256 值应完全相同。安装 GitHub CLI 后，也可以验证构建来源证明：

```bash
gh attestation verify Scholar-Workspace-vX.Y.Z.zip --repo SuperJayLiu/workspace-for-all
```

## 3. 启动

### 命令行

macOS / Linux：

```bash
cd "/path/to/Scholar-Workspace-vX.Y.Z"
python3 server.py
```

Windows PowerShell：

```powershell
cd "C:\path\to\Scholar-Workspace-vX.Y.Z"
py -3 server.py
```

浏览器会打开 <http://127.0.0.1:8765/>。关闭终端会停止服务，数据不会丢失。

### 双击启动

- macOS：`启动.command`
- Windows：`启动.bat`

### 登录时自动启动（可选）

- macOS：双击 `安装-Mac.command`；撤销时双击 `卸载自启-Mac.command`
- Windows：双击 `安装-Windows.bat`；撤销时双击 `卸载自启-Windows.bat`

安装器会检查 Python 3.9+，不会安装第三方包。

## 4. 首次设置

首次打开会显示向导。所有外部功能均为可选：

- 文献文件夹可指向 Zotero、EndNote、Mendeley 或普通 BibTeX/RIS/CSL-JSON/NBIB 导出文件。
- Git 同步应使用你自己的**私有仓库**。
- AI、日历、邮件、Overleaf 和通知渠道不配置也不影响核心工作台。
- English beta 可通过顶部的 `EN` 按钮切换。

密钥、访问码和本机路径存入 `local/`，不会进入 Git。不要把个人数据推回公共源码仓库。

## 5. 局域网访问

先在“设置 → 远程访问与手机”设置访问码，再运行：

- macOS：`局域网启动.command`
- Windows：`局域网启动.bat`

远程访问默认只读。不要进行路由器端口转发，也不要把服务直接暴露到公网。

## 6. 更新

1. 下载并解压新版本到单独目录。
2. 在旧工作台目录运行：

```bash
python3 升级.py "/path/to/new/Scholar-Workspace-vX.Y.Z"
```

先预览可使用 `--dry-run`。升级器会先备份，再替换代码并保留 `data/`、`local/` 和 `attachments/`。

## 7. 排错

- 页面打不开：访问 <http://127.0.0.1:8765/api/ping>，并确认没有另一个进程占用 8765 端口。
- Python 版本错误：确认实际启动命令对应 Python 3.9+；Windows 优先使用 `py -3`。
- macOS 阻止 `.command`：在 Finder 中右键文件，选择“打开”；只运行从本仓库 Release 下载并验证过的文件。
- 想检查安装：运行 `python3 tests/platform_smoke.py`。它只使用临时副本。
- 安全问题：请按 [SECURITY.md](../SECURITY.md) 私下报告。
