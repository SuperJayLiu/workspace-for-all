# 安装与使用（Mac / Windows 通用）

只有三步：装 Python → 启动 → 接上 Git。全部一次性。

---

## 一、准备 Python

**Mac**：系统自带 Python 3，终端里输 `python3 --version` 有版本号就行。没有的话装 Xcode 命令行工具：`xcode-select --install`。

**Windows**：去 python.org 下载安装，**安装时务必勾选 "Add Python to PATH"**。装完在 PowerShell 里输 `python --version` 验证。

不需要 pip install 任何东西——整个服务只用标准库。

## 二、启动

把工作台文件夹放到你想要的位置（建议放进 OneDrive 或任意常用目录均可，Git 才是同步主力）。

**Mac** 终端：

    cd "/你的路径/scholar-workspace"
    python3 server.py

**Windows** PowerShell：

    cd "C:\你的路径\scholar-workspace"
    python server.py

浏览器会自动打开 `http://127.0.0.1:8765`。关掉终端就停止服务，数据不会丢。

### 开机自启（可选，建议开）

**Mac**：把下面存成 `~/Library/LaunchAgents/com.scholar.workspace.plist`，改掉两处路径，然后 `launchctl load ~/Library/LaunchAgents/com.scholar.workspace.plist`。

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>com.scholar.workspace</string>
  <key>ProgramArguments</key>
  <array>
    <string>/usr/bin/python3</string>
    <string>/你的路径/scholar-workspace/server.py</string>
    <string>--no-open</string>
  </array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
</dict></plist>
```

**Windows**：新建一个 `启动工作台.vbs` 放进「启动」文件夹（Win+R 输 `shell:startup`）：

```vbs
CreateObject("WScript.Shell").Run "python ""C:\你的路径\scholar-workspace\server.py"" --no-open", 0
```

开机自启的意义：页面没打开时，定时备份和 Git 同步照常进行。

## 三、接上 Git（这是 Win↔Mac↔云端 Claude 的桥）

1. 在 GitHub 建一个**私有**仓库，例如 `scholar-workspace`（不要勾选任何初始化文件）。
2. 在设置页填入仓库 HTTPS 地址 → 点「初始化仓库」→ 点「立即同步」。
3. 第一次推送会要用户名和密码：**密码填 Personal Access Token**（GitHub → Settings → Developer settings → Personal access tokens → 勾 `repo` 权限）。

   免去每次输入：
   - Mac：`git config --global credential.helper osxkeychain`
   - Windows：`git config --global credential.helper manager`

4. **第二台电脑**：`git clone 你的仓库地址`，进目录运行 `server.py`，然后在设置页填这台机器自己的路径（论文根目录、OneDrive 备份目录）。这些路径存在 `local/`，不会互相覆盖。

### 换机器时的习惯

打开工作台前先点一下左下角同步（或它每 3 分钟自动检查一次）。
如果两台机器都改了同一条记录，Git 会提示冲突——因为每条记录是单独的文件，冲突范围很小，通常直接保留新的那份即可。

## 四、数据放在哪、什么会同步

| 位置 | 内容 | 同步 |
|---|---|---|
| `data/` | 稿件、期刊、已刊、会议、文献、想法、日程、AI 报告、设置 | ✅ Git |
| `data/_claude/` | 信箱、回信、台账、额度状态 | ✅ Git |
| `local/` | 饮食运动等生活数据、密钥、备份、本机路径 | ❌ 只在本机 |
| OneDrive 备份目录 | 每日长期备份 zip | 由 OneDrive 客户端同步 |

生活数据不进 Git 是刻意的隐私边界。想改的话在 `.gitignore` 里调整。

## 五、常见问题

**打开是空白 / 提示连不上服务** — 服务没跑起来。回到终端看看有没有报错，或换个端口：`python3 server.py --port 8790`。

**端口被占用** — 同上，换端口。

**图表显示不出来** — 稿件的「论文文件夹」要填对（绝对路径，或相对于设置里的论文根目录）；PDF 渲染需要联网加载一次 pdf.js，之后浏览器会缓存。

**Excel 导入后字段名很奇怪** — 正常，第一版是原样保留列名。把表发给 Claude，说清楚哪列对应什么，它会统一改。

**恢复到几小时前** — 设置页「备份时光机」→ 刷新列表 → 选一个快照点恢复。恢复前会自动把当前状态另存一份。

**想加新功能** — 在 Cowork 里直接说。改完 Git 一同步，两台电脑都更新。
