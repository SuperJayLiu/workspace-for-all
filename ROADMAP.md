# Roadmap

Scholar Workspace is intentionally local-first, readable-file based, and dependency-light. Roadmap items should preserve those constraints.

## Now — public v1

- Continue the English beta review across secondary explanatory text and sample content
- Validate installation and upgrades on real Windows and macOS machines
- Add a short product walkthrough using the new sanitized screenshots
- Validate the new keyboard, focus, dialog, contrast, and screen-reader support with assistive-technology users

## Next

- Expand browser/device testing with real Safari and mobile sessions
- Make imports easier to preview, validate, and undo
- Improve documentation for private Git synchronization and backup recovery
- Add opt-in diagnostics that remain content-free and privacy preserving

## Later / evaluating

- Full-text PDF indexing without a mandatory cloud service
- Optional export/import bundles for moving between private repositories
- Community-maintained translations beyond Chinese and English

## Non-goals for the current design

- Hosting users' research data on a Scholar Workspace cloud service
- Requiring an account, subscription, database, or frontend build system
- Silent collection of analytics or usage history

Ideas and evidence from real use are welcome through the [feature-request template](https://github.com/SuperJayLiu/workspace-for-all/issues/new?template=feature_request.yml).
