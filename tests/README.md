# 极端测试套件

这十八个脚本是给工作台做"体检"的。平时不用管；如果你改过 `server.py`、`app/js/` 里的东西，
或者哪天觉得系统行为不对劲，就跑一遍，看有没有红叉。

## 怎么跑

在工作台目录（也就是有 `server.py` 的那个文件夹）里打开终端：

```bash
python3 tests/1-后端.py         # 数据层：加密备份、额度调度、CSV/ICS 解析、Webhook
python3 tests/3-接口与PDF.py     # HTTP 层：畸形请求、目录穿越、密钥泄漏、PDF 提取、备份恢复
python3 tests/4-鲁棒性.py        # 崩溃恢复：id 注入、状态文件损坏、强杀重启、冲突检测
python3 tests/5-远程访问.py      # 访问码、只读锁、失败锁定、远程禁做的那几件事
python3 tests/8-Overleaf进展.py  # LaTeX 字数、节级 diff、进展记录落库
python3 tests/10-新功能.py       # 邮箱收件、领域助读、批量删除、表格列名映射、同步日志
python3 tests/11-关联后端.py     # 跨库关联：双向写、去重、穿越防护、悬空清理
python3 tests/13-日历时区.py     # 日历解析与跨时区边界
python3 tests/14-文献索引.py     # 文献导入、检索与 PDF 路径解析
python3 tests/15-并发与负载.py   # 并发读写、响应大小与负载边界
python3 tests/16-搜索与新功能.py # 搜索、诊断包与新增安全边界
python3 tests/18-畸形输入.py     # 全路由畸形输入与路径攻击
python3 tests/19-学术雷达.py     # 候选池、来源校验与提交流程
```

浏览器那五份需要 Node 和 Playwright，跑起来会开一个无头浏览器：

```bash
python3 server.py --port 8799 --no-open &     # 先起一个测试用的服务
node tests/2-前端.js                            # XSS、极端长度、600 条渲染性能、农历边界
node tests/6-手机与远程界面.js                    # 375px 窄屏、抽屉、只读态
node tests/7-AI与快捷链接.js                     # AI 面板、快捷链接、外部应用协议
node tests/9-界面改动.js                         # 隐藏示例、统计明细、批量条、模板回应
node tests/12-关联界面.js                        # 关联 chip、选择器、跳转、死链兜底
```

跑完屏幕上是一列 ✓，末尾写"全部通过"就说明没问题。出现 ✗ 时它会把失败原因打出来。

## 它们会不会动我的数据

会写入几条测试记录，跑完自己删掉。第 4 个脚本会临时把 `config.json`、`quota.json` 等
改坏再改回来（用来验证损坏后还能不能启动），过程中会强杀几次服务进程 —— 所以**跑测试时
先别在浏览器里编辑东西**。真实数据（示例记录之外的）不会被碰。

保险起见，跑之前可以在设置页点一次"立即备份"。

## 第 5、6 份（远程与手机）

```bash
python3 tests/5-远程访问.py      # 访问码、只读、禁区、锁定、会话
```

第 5 份会让服务临时监听 0.0.0.0，然后用本机网卡地址连自己，以此模拟"从别的设备进来"。
它会临时改写访问码和安全设置，跑完自动还原（写在 finally 里）。

```bash
python3 server.py --port 8799 --no-open &
node tests/6-手机与远程界面.js    # 四种手机尺寸、抽屉、只读界面、弹窗溢出
```

第 6 份用无头浏览器模拟 iPhone SE / iPhone 15 Pro / 小屏安卓 / iPad 竖屏四种尺寸，
逐页检查有没有横向溢出、顶栏按钮是否被挤出屏幕、弹窗和向导会不会超出可视区域。

## 第 7 份（AI 直连与快捷链接）

```bash
python3 server.py --port 8799 --no-open &
node tests/7-AI与快捷链接.js
```

检查设置页和向导里的 AI 直连配置是否讲清了"按量付费"、未配 key 时报错是否是人话、
向导那一步能不能跳过，以及快捷入口在填了软件协议时会不会先尝试唤起桌面软件、
唤不起来能否自动退回网页。

## 第 8 份（Overleaf 写作进展）

```bash
python3 tests/8-Overleaf进展.py
```

连不上真的 Overleaf 也能跑：用一个本地 git 仓库假扮 Overleaf 项目，把「clone →
又写了一笔 → 再同步」整个流程走一遍，验证字数统计（注释、公式、命令都不算进正文）、
增删行、章节识别、同一天进展记录的累加，以及 token 不会出现在任何日志里。

## 第 9 份（界面改动）

```bash
python3 server.py --port 8799 --no-open &
node tests/9-界面改动.js
```

盯的是这几件事：每张卡上的「隐藏示例」按钮点一次是否全站生效且不删数据、
四个统计卡能否点开明细、列表整行能否点、布局编辑里的 ⚙ 能否改标题/限条数/加备注、
顶栏按钮有没有文字、完成记录有没有汇进今日页、日历顶部是否够紧凑且只有日程区滚动。

## 第 10 份（新功能 · 服务端）

```bash
python3 tests/10-新功能.py
```

盯 v3.4–v3.8 新加的那几块：邮箱收件（没配 / 连不上都要说人话且不崩、状态接口不吐明文密码）、
领域助读（挑领域、去重、排队、同一周不重复排）、品牌名与示例开关能否落盘、
批量删除是否真删干净且进回收站、表格导入的列名自动映射与空标题行跳过、箴言库完整性。

第 9 份（界面）也扩到了 11 节，新增本周一览、多选批量操作、工作台名称自定义与固定角标、
记录后的系统回应与「问 AI」话术模板。
